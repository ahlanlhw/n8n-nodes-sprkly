# Templates

Ready-made n8n workflows that use sprkly. Import a `workflow.json` into n8n. They are not part of the npm package.

- `sheets-content-calendar/`: a Google Sheet becomes your posting calendar. Uses the sprkly node. Use it on self-hosted n8n.
- `sheets-content-calendar-http/`: the same calendar with built-in n8n nodes only. Use it on n8n Cloud, or if you cannot install community nodes.

Each folder has a README with the setup steps.
